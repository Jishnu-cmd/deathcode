# ☠️ Death Code: The Kira Protocol

An immersive Death Note themed technical coding and SQL investigation event platform.

## 🚀 Features

- **Round 1: The Notebook** — Standard SQL MCQs with lives and score system.
- **Round 2: Kira's Code** — Query repair with Ask L hints and Ryuk's Deal risk multiplier.
- **Round 3: SPK Surveillance** — Keyword ordering and query assembly.
- **Round 4: L's Final Investigation** — Multi-table relational forensics and binary decryption to identify Kira.
- **Anti-Cheat & Proctoring Engine** — Fullscreen surveillance, tab-switching telemetry, and anti-tamper controls.
- **Real-Time Live Leaderboard** — Live updates via WebSockets and projector mode support.
- **Google Form Integration** — Post-loss debrief form and victory certificate submission.

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Tailwind CSS, Lucide Icons
- **Backend**: Node.js, Express, WebSocket (`ws`), Native `node:sqlite`

## 📦 Quick Start

### 1. Install Dependencies
```bash
# Server dependencies
cd server && npm install

# Client dependencies
cd ../client && npm install
```

### 2. Launch the Application
```bash
# From the root directory
node start-all.js
```

- **Client Dev Server**: [http://localhost:3000](http://localhost:3000)
- **Backend API & WebSockets**: [http://localhost:5000](http://localhost:5000)
